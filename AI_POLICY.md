# AI Usage Policy

1. Agents can in no way interact with the repository. This includes but is not limited to:
    1. Creating, commenting, and closing issues.
    2. Creating, co-authoring, commenting, closing, pull requests (PR).
    3. Writing code reviews.

    All interactions **MUST** be done by a human. You are responsible for anything that you write or commit; AI assistance must be **fully** reviewed *and edited* by a human before submission.

2. Any generated code or assistance from an agent, Large Language Model (LLM), or AI tool must be disclosed inside the PR or issue. You must also state which tool was used and describe the extent of the assistance or work that was done by AI.

3. If AI is not disclosed but a maintainer suspects its usage, the PR or issue is subject to be closed without reason.

4. All generated code **MUST** be fully verified via testing. Code that hypothetically works will be hypothetically merged. AI can not be used to write code for environments or platforms that you do not have access to actually test on/with.

5. Generation of media other than text is fully forbidden. This includes but is not limited to art, images, videos, audios, ...
  
6. Any code comment must be concise, correct, and useful to the code in which it aims to provide context for. Remove all AI comments which are verbose, trivial, or irrelevant.


Failure to comply with the AI Usage policy may result in your issue/PR being closed, and/or a ban from the survev project.
